GeoAFT

Adapting how representations relate to one another, not only the representations themselves.

A pretrained Transformer learns two things: representations, and a rule for comparing them. Parameter-efficient fine-tuning overwhelmingly changes the first. GeoAFT asks what happens if we adapt the second.

We add a small, structured compatibility geometry to attention. It starts exactly at the pretrained model. We then study when changing relations buys something that ordinary weight adaptation does not.

01 · The observation

Fine-tuning usually changes the representations

Inside every attention head, tokens are mapped to queries and keys. A compatibility function, usually a scaled dot product, then decides how strongly each query attends to each key. Parameter-efficient fine-tuning (PEFT) methods such as LoRA adapt the maps that produce queries and keys. The compatibility rule itself is usually inherited unchanged from pretraining.

Representations
The features a pretrained model produces. In attention, these are the queries q and keys k.
Relations
The compatibility function s(q,k) that decides which representations attend to one another.

This does not mean that Q/K adaptation cannot change attention scores. It does, indirectly, by moving q and k. The difference is where adaptation lives and how it is parameterized, and that difference is what makes the comparison worth studying.

Can adaptation change the relation between representations, rather than only the representations?

02 · The intuition

Changing the geometry changes what counts as similar

Hold one query and seven keys fixed. Under the dot product, the most compatible key is the one furthest along the query’s direction, which is not the nearest one. Euclidean distance prefers the nearest neighbour. Taxicab (L1) distance prefers neighbours along the coordinate axes. An anisotropic Mahalanobis metric prefers neighbours along a direction it treats as cheap. The winner changes every time, and no point has moved.

03 · The method

GeoAFT adds a structured residual to the compatibility score

GeoAFT keeps the pretrained score and adds a trainable, structured geometry term on top of it:

Sij=sbase(qi,kj)+αhg¯ϕ(Pqqi,Pkkj),Aij=softmaxj∈𝒱(i)(Sij)

Here gϕ is a geometry family, such as a learned Lp distance or a Mahalanobis metric, acting on low-dimensional projections of the query and key. g¯ϕ is that score centred over each query’s valid keys 𝒱(i), and αh is a per-head gate.

  • Starts from the pretrained model. Each gate αh is initialized at zero, so at the start of training the attention is exactly the pretrained attention. Adaptation departs from base behaviour rather than from a new architecture.
  • Small and structured. What gets trained is the geometry itself (a metric, an exponent, a projection), not a generic learned scorer.
  • Softmax-aware bookkeeping. Centring removes per-query constants that softmax ignores anyway. Masked keys never enter the centring arithmetic.

04 · The evidence

What we have demonstrated so far

We first test GeoAFT where the right answer is known. A synthetic teacher generates attention from a known compatibility function over fixed representations. Every method then adapts the same frozen base toward that target.

Reading the numbers: oracle-gap recovery R

R=Lbase−LmethodLbase−Loracle

L is the KL-divergence loss to the target attention on held-out data, as defined in the project protocol. The unadapted model starts at Lbase, and Loracle is the oracle reference. R=0% means no improvement over the base, and R=100% means the method does as well as the oracle. R measures how well a compatibility function is recovered. It is not classification accuracy.

Scope. These are controlled synthetic results. Two controls set their limits. A fixed Lp geometry bank nearly closed the Lp gap on its own, which left little room to show superiority. An exact quadratic score control beat the Mahalanobis overlay, which is consistent with the equivalence in §05. Not every registered superiority comparison passed, and no natural-task or state-of-the-art result is claimed. Recovering a target is not the same as adding capacity.

The baselines include Q/K adaptation, fixed geometry, generic learned scores, projected-dot controls and exact structural controls. Experimental design and full results →

05 · What geometry adaptation buys

Three different answers to “is it new?”

A geometry update can look different from a weight update and still compute the same function. Before asking whether geometry adaptation helps, we have to ask which kind of change it is.

  1. {{svg:assets/geoaft/fig5-regime-1.svg}}

    1

    Exact reparameterization

    ✓ Established analytically

    The geometry change describes a function that a conventional scorer already represents. Squared Mahalanobis compatibility expands as

    −(q−k)⊤M(q−k)=2q⊤Mk−k⊤Mk−q⊤Mq

    The last term is the same for every key, so row-wise softmax cancels it. A Mahalanobis overlay is therefore exactly softmax-equivalent to a bilinear score plus a key-dependent quadratic bias, which is a known score family.

  2. {{svg:assets/geoaft/fig5-regime-2.svg}}

    2

    Economical parameterization

    ◐ Supported in controlled experiments

    A structured geometry may represent the same useful interaction, or a close approximation of it, with far fewer optimized parameters. On the nonlinear target, 46 trainable parameters fit about as well as the tested 8,705-parameter PairMLP.

  3. {{svg:assets/geoaft/fig5-regime-3.svg}}

    3

    Distinct adaptation capacity

    ○ Under investigation

    Some compatibility changes may be hard for a restricted conventional family to reach. For the score matrix this can happen in principle: a rank-r Q/K update changes it by rank at most 2r, while an L1 geometry on N keys can produce centred patterns of the maximal rank N−1. Whether that difference survives the value and output path and appears in downstream tasks is the open question.

The Mahalanobis result is why this project is not about “non-dot geometry is better”. Near-perfect recovery can come from a reparameterization of a known score family.

06 · Why it matters

Where should adaptation spend its capacity?

Fine-tuning works within a budget of parameters, memory and optimization effort. GeoAFT turns a design default, the compatibility rule, into something that can be adapted and compared against matched conventional adaptation.

Our working hypothesis is that relations matter most when representations are constrained: frozen or compressed features, small adaptation budgets, or similarity-critical tasks. Where representations are flexible, ordinary PEFT may absorb the same change. Either outcome is informative. The goal is a map of when adaptation should change representations, and when it should change how they interact, not a claim that one geometry always wins.
