GeoAFT

Adapting how representations relate to one another, not only the representations themselves.

A pretrained Transformer learns representations and a rule for comparing them. Parameter-efficient fine-tuning mostly changes the first. GeoAFT adapts the second: a small, structured geometry added to the attention score, starting exactly at the pretrained model.

GeoAFT in brief

The question

Can adaptation change relations?

Methods such as LoRA adapt the projections that produce queries and keys. The compatibility rule that compares them is usually inherited unchanged from pretraining.

The method

A gated, structured term on the score

\[ S_{ij} = s_{\mathrm{base}}(q_i, k_j) + \alpha_h\, \bar g_\phi\big(P_q q_i,\; P_k k_j\big) \]

\(g_\phi\) is a trainable geometry, such as a learned \(L_p\) distance or a Mahalanobis metric. Each gate \(\alpha_h\) starts at zero, so training begins from exactly the pretrained attention.

What geometry adaptation buys

Three different answers to “is it new?”

  1. Exact reparameterization

    ✓ Established analytically

    A Mahalanobis overlay is softmax-equivalent to a known bilinear-plus-key-quadratic score, so near-perfect recovery there is not new capacity.

  2. Economical parameterization

    ◐ Supported in controlled experiments

    A structured geometry can fit about as well as a generic scorer with far fewer trainable parameters.

  3. Distinct adaptation capacity

    ○ Under investigation

    Whether geometry reaches changes that restricted Q/K updates cannot, and whether that survives downstream, is the open question.

The goal is a map of when adaptation should change representations and when it should change how they interact, not a claim that one geometry always wins.
