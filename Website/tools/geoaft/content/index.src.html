GeoAFT

Adapting how representations relate to one another, not only the representations themselves.

A pretrained Transformer learns representations and a rule for comparing them. Fine-tuning usually changes the first. GeoAFT adapts the second.

GeoAFT at a glance

The idea

LoRA-style methods change how queries and keys are produced. GeoAFT changes how they are compared:

\[ S_{ij} = s_{\mathrm{base}}(q_i, k_j) + \alpha_h\, \bar g_\phi\big(P_q q_i,\; P_k k_j\big) \]

The gate \(\alpha_h\) starts at zero, so training begins from exactly the pretrained attention.
